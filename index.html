CLIENT-SIDE · FPS

Mouse aiming and weapon spread

This client-side helper turns the mouse position into a world-space aim point and optionally adds weapon spread. 

local function getMouseWorldDestination(spreadAngleRadians: number?): Vector3
    local mouseLocation = UserInputService:GetMouseLocation()
    local unitRay = Camera:ScreenPointToRay(mouseLocation.X, mouseLocation.Y)

    local filterList: { Instance } = {}
    local character = LocalPlayer.Character
    if character then
        table.insert(filterList, character)
    end

    local raycastParams = RaycastParams.new()
    raycastParams.FilterType = Enum.RaycastFilterType.Exclude
    raycastParams.FilterDescendantsInstances = filterList

    local maxRange = CurrentWeaponConfig and CurrentWeaponConfig.Range 
    local baseDirection = unitRay.Direction

    if spreadAngleRadians > 0 then
        local randomAngle = math.rad(math.random(0, 360))
        local spreadRadius = math.tan(spreadAngleRadians) * math.sqrt(math.random())
        local cameraFrame = Camera.CFrame
        local offset = (
            cameraFrame.RightVector * math.cos(randomAngle)
            + cameraFrame.UpVector * math.sin(randomAngle)
        ) * spreadRadius

        baseDirection = (baseDirection + offset).Unit
    end

    local result = workspace:Raycast(
        unitRay.Origin,
        baseDirection * maxRange,
        raycastParams
    )

    return result and result.Position
        or (unitRay.Origin + baseDirection * maxRange)
end

It excludes your own character model, applies the weapon’s range and returns either the hit point or the end of the aim ray. Used for client side aiming.

SERVER-SIDE · ABILITIES

Meteor strike damage

This server-side function finds living players within the strike radius, skips the caster, and applies damage. 

local function executeServerMeteorStrike(caster: Model, targetPos: Vector3)
    local casterPlayer = Players:GetPlayerFromCharacter(caster)

    for _, player in ipairs(Players:GetPlayers()) do
        if player == casterPlayer then
            continue
        end

        local character = player.Character
        local root = character and character:FindFirstChild("HumanoidRootPart")
        local humanoid = character and character:FindFirstChildOfClass("Humanoid")

        if root and root:IsA("BasePart")
            and humanoid and humanoid:IsA("Humanoid")
            and humanoid.Health > 0 then
            -- Measure distance across the ground plane; height is ignored.
            local flatRootPosition = Vector3.new(
                root.Position.X,
                targetPos.Y,
                root.Position.Z
            )
            local distance = (flatRootPosition - targetPos).Magnitude

            if distance <= EXPLOSION_RADIUS then
                humanoid:TakeDamage(METEOR_DAMAGE)
            end
        end
    end
end

The distance check is horizontal, so elevation does not affect the blast radius.
